# Adopters

Public projects using Lathe to generate a CLI from declared API specs.

- [DaoCloud/daocloud-skills](https://github.com/DaoCloud/daocloud-skills) — Swagger 2.0. Generated `dce` CLI and agent Skill wrapping DaoCloud Enterprise REST APIs across product modules.
- [langgenius/mosoo-connector](https://github.com/langgenius/mosoo-connector) — OpenAPI 3 and policy-curated GraphQL. Generated `mosoo` CLI and Skill for the mosoo Agent API on cloud, local, and self-hosted targets.
- [samzong/awire](https://github.com/samzong/awire) — OpenAPI 3. Generated `awirectl` CLI for the awire management API that routes GitHub events to Feishu, Slack, or Telegram.

## Add an adopter

If you use Lathe in a public or internal project and can share a short note, open a pull request with:

- Organization or project name.
- API spec type: Swagger 2.0, OpenAPI 3, protobuf with `google.api.http`, or policy-curated GraphQL.
- Generated CLI use case.
- Public link, if available.

Private/internal users may list only a short anonymized note if public naming is not possible.
